## 1. Visual Theme & Atmosphere

Modern institutional design emphasizing agricultural research excellence and academic leadership. Premium aesthetic with emerald green representing growth and sustainability, gold accents for prestige, and clean contemporary typography.

- **Visual style:** modern, institutional, premium
- **Color stance:** emerald, gold, neutral, authentic
- **Design intent:** Convey research credibility, academic excellence, and modern agriculture innovation while maintaining institutional authority and accessibility
- **Accessibility:** WCAG 2.1 AA minimum, high contrast, semantic HTML structure

## 3. Typography System

### Font Families
- **Primary Font:** Inter (sans-serif) — Modern, clean, highly readable

- **News Cards:** Image scale on section visibility

### Hover States
- **Buttons:** Brightness increase, subtle shadow growth (150ms ease-out)
- **Links:** Underline animation from left (100ms ease-in-out)
- **Cards:** 4px lift with shadow enhancement (200ms ease-out)
- **Icons:** Color shift to Gold Accent (100ms ease-in-out)

### Click States
- **Buttons:** Active scale 0.98, shadow decrease
- **Links:** Color darker for 150ms then revert

### Loading States
- **Skeleton Screens:** Emerald Primary gradient pulse (1.5s loop)
- **Button Loading:** Animated dots or spinner icon

### Transitions & Timing
- **Global:** All transitions use ease-in-out easing
- **Micro-interactions:** 100-150ms (hover, focus)
- **Component animations:** 200-300ms (transitions, transforms)
- **Page transitions:** 400-600ms (fade, slide)

## 7. Responsive Behavior

### Mobile-First Strategy
- **Base:** Mobile design (320px) with flexible typography
- **Tablet:** Enhanced spacing, optimized touch targets (48px minimum)
- **Desktop:** Full feature set, advanced layouts

### Touch Considerations
- **Button/Link min height:** 48px
- **Touch spacing:** 16px between interactive elements
- **Hover states:** Converted to active states on mobile
- **Overflow:** Horizontal scroll on cards instead of cramping

### Image Optimization
- **Hero image:** Responsive srcset for 3x resolutions
- **Card images:** Lazy loading with skeleton placeholders
- **Format:** WebP primary with JPEG fallback

## 8. Accessibility Requirements

### Color Contrast
- All text meets WCAG AA standards (4.5:1 for body, 3:1 for large text)
- Do not rely on color alone for information (use icons, patterns, text)

### Semantic HTML
- Proper heading hierarchy (H1, H2, H3, etc.)
- ARIA labels for icon-only buttons
- Form labels explicitly associated with inputs
- Image alt text describing content accurately

### Keyboard Navigation
- All interactive elements keyboard accessible (Tab order logical)
- Visible focus indicators (min 3px outline in brand color)
- Skip navigation link in header

### Screen Reader
- Semantic landmarks (nav, main, footer, aside)
- Meaningful link text (avoid "click here", "read more")
- Form validation messages announced
- Loading states communicated

## 9. Internationalization (i18n)

### Language Support
- **Primary:** Thai (ไทย) - RTL considerations needed
- **Secondary:** English
- **Toggle:** Language switcher in header and footer

### Thai Typography Considerations
- Font: Prompt (optimized for Thai)

### Content Strategy
- All UI text available in both languages
- Direction: LTR for English, handle Thai properly
- Number formatting: Thai numerals option
- Currency: ฿ (Baht)
